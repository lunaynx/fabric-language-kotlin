# legacy-fabric-language-kotlin

[![modrinth-badge](https://img.shields.io/modrinth/dt/legacy-fabric-language-kotlin?label=Modrinth&logo=Modrinth&style=flat-square)](https://modrinth.com/mod/legacy-fabric-language-kotlin/versions)

Unofficial distribution of
[Fabric Language Kotlin](https://github.com/FabricMC/fabric-language-kotlin)
aimed at Babric, Legacy Fabric, and Ornithe for Minecraft versions below 1.14.

This is essentially an identical fork of FLK that only exists to ease launcher
and modpack use due to Modrinth quirks, because it already works on these
otherwise. If you're looking for a Maven dependency, please depend on the
upstream project instead!
